#### 🧭 Méthode

- **Spec d'abord** — chaque projet est piloté par un document de spécification versionné.
- **Workflow Git pro** — branches `feat/` `fix/`, [Conventional Commits](https://www.conventionalcommits.org/), Pull Requests relues, squash merge.
- **Qualité automatisée** — lint, typecheck et tests en CI sur chaque PR, preview deployments Vercel.
- **Dev assisté par IA, encadré** — conventions explicites dans chaque repo pour un code cohérent et relu.
